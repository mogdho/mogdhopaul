How to make the Copilot key open Gemini (or ChatGPT) instead

By Mogdho Paul23 October 20262 min read

Short answer

Recent versions of Windows 11 let you change the Copilot key, but only to apps from the Microsoft Store, so you can't pick Gemini that way. Install Gemini as an app from Chrome or Edge, then use a small app like Copilot2Gemini to put it on the key.

Most new Windows laptops have a Copilot key next to the space bar. It's a good spot for an AI assistant, but it opens Microsoft Copilot, and many people would rather use Gemini, ChatGPT or Claude.

Can Windows change it?

Partly. In recent versions of Windows 11 you'll find Settings, Personalization, Text input, Customize Copilot key on keyboard. It lets you choose Search or another app, but only apps from the Microsoft Store show up. Gemini in your browser isn't one of them.

The one-click fix · Windows app

Copilot2Gemini

Makes the Copilot key open Gemini, ChatGPT or Claude.

Get Copilot2Gemini

Step 1: install Gemini as an app

This gives Gemini its own window, like a normal app, instead of a browser tab.

  1. Open gemini.google.com in Chrome, Edge or Brave.
  2. Click the three-dot menu at the top right, then Save and share (or Apps), then Install page as app.
  3. Click Install.

Step 2: put it on the Copilot key

Copilot2Gemini is a free little app I made for this. It finds the Gemini app you just installed by itself, so there's nothing to set up.

  • Press the Copilot key and Gemini opens.
  • Press it again and Gemini hides.
  • Press it while Gemini is behind other windows and it comes back to the front.

No Copilot key on your keyboard? Win + C does the same.

Prefer ChatGPT or Claude?

Install chatgpt.com or claude.ai as an app the same way. Then right-click the Copilot2Gemini icon next to the clock, choose Assistant, Rescan installed apps, and pick the one you want.
