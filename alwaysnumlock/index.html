AlwaysNumLock

Keeps Num Lock on, always. Your number pad types numbers, every time, even after sleep.

Download AlwaysNumLock

Free · Windows 10 and 11 · Nothing to install

What AlwaysNumLock does

Ever typed a phone number and got the cursor jumping around instead? Num Lock was off. AlwaysNumLock switches it on and keeps it on, so the number pad always types numbers.

  • NormallyWith AlwaysNumLock
  • You bump the Num Lock key by accidentNormally: Turns offWith AlwaysNumLock: Stays on
  • Your PC wakes up from sleepNormally: Often offWith AlwaysNumLock: On
  • You come back from the lock screenNormally: Sometimes offWith AlwaysNumLock: On
  • You type your PIN to sign inNormally: Sometimes offWith AlwaysNumLock: On, if you choose

It runs quietly by the clock and uses almost no memory. Need the number pad as arrow keys for a game? Pause it with one click.

Set it up in a minute

  1. Download it

    Click the download button. You get one small file, AlwaysNumLock.exe. There is nothing to install.

  2. Double-click the file

    Windows asks whether the app may make changes. Click Yes.

    See “Windows protected your PC”? Click More info, then Run anyway. Windows shows this for small apps from independent makers. It doesn’t mean something is wrong.

  3. Answer one question

    The first time, it asks if Num Lock should also be on at the Windows sign-in screen. Click Yes if you sign in with a number PIN.

  4. That’s it

    A small 1-2-3 icon appears next to the clock, and Num Lock now stays on. To have it start every time you turn on your PC, right-click the icon and tick Start with Windows.

    Can’t see the icon? Click the small up arrow next to the clock.

The menu by the clock

Right-click the 1-2-3 icon to change how it works.

Closes it until you open it again.

Removing it

  1. Right-click the 1-2-3 icon and untick Start with Windows. If you like, untick Num Lock on at sign-in screen too.
  2. Right-click the icon again and click Exit.
  3. Delete AlwaysNumLock.exe, and the small settings file with the same name next to it.
