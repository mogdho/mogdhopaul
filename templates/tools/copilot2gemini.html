What it does

New laptops have a Copilot key. If you’d rather use Gemini, Copilot2Gemini makes that key yours: one press opens your assistant in its own neat window, the next press tucks it away.

Opens it
Copilot assistant is in front
Hides it
Copilot assistant is behind other windows
Brings it back to the front
Ctrl + Copilot
Opens a second window

No Copilot key on your keyboard? Win + C does exactly the same.

Set it up in two minutes

  1. Install Gemini as an app

    Skip this if you already have. In Chrome, Edge or Brave, open gemini.google.com. Click the three-dot menu at the top right, then Save and share (or Apps), then Install page as app, and click Install. Gemini now opens in its own window.

  2. Download Copilot2Gemini

    Click the download button. You get one small file, Copilot2Gemini.exe. There is nothing to install.

  3. Double-click the file

    Windows asks whether the app may make changes. Click Yes.

    See “Windows protected your PC”? Click More info, then Run anyway. Windows shows this for small apps from independent makers. It doesn’t mean something is wrong.

  4. Press the Copilot key

    A message says Found Google Gemini. Press the Copilot key and Gemini opens. There is nothing else to set.

    To have it start every time you turn on your PC, right-click its icon next to the clock and tick Start with Windows.

Skipped step 1? The key still works: it opens Gemini in a normal browser tab instead.

Prefer ChatGPT or Claude?

  1. Open the site, for example chatgpt.com or claude.ai, and install it as an app, the same way as Gemini in step 1.
  2. Right-click the Copilot2Gemini icon next to the clock, then Assistant, then Rescan installed apps.
  3. Pick your new assistant from the Assistant list. It’s remembered from now on.

If something seems off

Gemini opens in a browser tab
Do step 1 above, then right-click the icon and choose Assistant, then Rescan installed apps.
The wrong Google account opens
If you installed Gemini in more than one browser profile, each one is listed under Assistant with its profile name. Pick the right one.
Windows Copilot still opens
Open Copilot2Gemini again and click Yes when Windows asks, or tick Start with Windows.

Removing it

  1. Right-click the Copilot2Gemini icon and untick Start with Windows.
  2. Right-click the icon again and click Exit.
  3. Delete Copilot2Gemini.exe, and the small settings file with the same name next to it.
